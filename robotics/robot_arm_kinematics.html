Practice activities

  1. Set both joint angles to zero. Predict the end-effector coordinates and explain the singularity.
  2. Set both links to 1 m and joint angles to 30° and 60°. Calculate x and y before checking the displayed results.
  3. Set the target to (1, 1) m with both links 1 m. Solve using both branches and compare the configurations.
  4. Request (3, 0) m with both links 1 m. Explain why the solver rejects the target.

Ideal rigid planar model; no collision detection, dynamics, actuator constraints or physical robot control. Joint angles cover a full revolution. Results are rounded for display.
