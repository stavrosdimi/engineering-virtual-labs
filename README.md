# engineering-virtual-labs
Interactive Virtual Laboratories and Simulations for Engineering, Science and Technology Education.

## Academic presentation and navigation conventions

- Present mathematical equations in professionally typeset mathematical notation, including inline expressions, displayed equations, calculated results and matrices, rather than programming syntax. Use standards-based native MathML exclusively for mathematical typesetting; do not use MathJax or other rendering libraries unless explicitly authorised by Stavros Dimitriou.
- Preserve literal programming syntax only in source-code examples, command lines and data representations where required.
- Open external references and documentation in new browser tabs using `target="_blank" rel="noopener noreferrer"`.
- Keep internal navigation in the same browser tab and preserve existing published URLs where possible.
- Validate mathematical accuracy, interactive behaviour and accessibility before recommending applications for student use.
- Display the author name **Stavros Dimitriou** immediately below the introductory description on every homepage, subject page, subpage and individual interactive application.
